# 🗲 DOM Web Page — Labyrinths of Patriarch

Небольшой интерактивный веб-проект, созданный в рамках учебных заданий по работе с DOM и JavaScript.

Проект представляет собой страницу из трёх интерактивных заданий, в которых используются создание и изменение DOM-элементов, обработка событий, пользовательский ввод и сортировка элементов списка.

## ✨ Возможности

### 1. Динамическое добавление текста

Кнопка «Выполнить» последовательно добавляет на страницу заранее заданные текстовые блоки.

При каждом нажатии также случайным образом изменяется цвет рамки блока.

### 2. Интерактивный список задач

Пользователь может:

- ввести собственную задачу;
- добавить её в список;
- удалить отдельную задачу;
- добавить задачу нажатием `Enter`.

Пользовательский текст создаётся как DOM-элемент и добавляется непосредственно в список.

### 3. Сортировка списка

На странице расположен список причин опоздать на пару.

Кнопка «Отсортировать список» перестраивает элементы списка в заранее определённом порядке.
